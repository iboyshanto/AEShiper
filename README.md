# AEShiper

AEShiper transfers selected Figma designs into Adobe After Effects as editable layers, organized precomps, raster assets, or a reference PNG.

## Install

### After Effects

Download the latest signed `AEShiper-vX.Y.Z.zxp` and its `.sha256` file from GitHub Releases. Install the ZXP with a compatible CEP extension installer, restart After Effects, then open **Window > Extensions > AEShiper** once to review destination and image settings.

### Figma

Install [AEShiper from Figma Community](https://www.figma.com/community/plugin/1678017504586586252/aeshiper). The plugin is free. Figma distributes published plugin updates automatically.

## Privacy and networking

Design and image data moves only between Figma and After Effects on the same computer through `127.0.0.1`. AEShiper has no analytics, telemetry, account system, cloud upload, or remote design endpoint. Both companions read the small public `release.json` file in this repository to display non-blocking update notices.

## Releases

Production downloads, checksums, release notes, and previous versions are available under [GitHub Releases](https://github.com/iboyshanto/AEShiper/releases).
